Advanced Topics

The common space, model and observation types connect regression, optimization and optional integrations. Start with normalization and visualization to understand your data and fitted image. Use degree selection, regularization and fixed controls to improve a model under explicit assumptions. Sampling and active learning help decide where to obtain additional observations; assembled domains describe how local charts connect. Objective minimization is a separate path for differentiable costs without regression targets.

Each practical guide explains when the feature is needed, provides runnable examples, and describes how settings affect results. Before/after figures state what changed and retain reproduction scripts and numerical evidence.

Follow a fit through the guides

Start by recording the domain, output units and measurement process. Use sampling and visualization to examine coverage before changing the model. Then choose capacity with held-out data. A larger degree can reduce bias, but increases controls and can worsen conditioning; regularization imposes an additional assumption rather than adding measurements.

Keep the evaluation set fixed while comparing settings. If you change both degree and training locations, a better result cannot be attributed to either change alone. Boundary constraints, coefficient penalties and output transforms should be recorded with every comparison because they change what problem is being solved.

FitResult.success describes numerical termination. Observation rank describes whether data identify the free controls, while held-out errors describe predictive performance. None replaces the others. An accurate interior fit can still miss an important boundary, and a regularized full-rank system can still have an underdetermined data matrix.

The category-theory chapter is a mathematical continuation of the geometric simploid guide. It is useful for understanding faces, degeneracies and gluing abstractly; it is not a prerequisite for fitting a square or prism. The scikit-learn guide uses the same core numerical model in estimator workflows. Exact subdivision in the splitting guide changes charts while preserving the represented function, so assess it differently from refitting.
